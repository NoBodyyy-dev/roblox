# Профиль художника

Заполняет агент Художника после интервью (`ASSETS_PROMPT.md` §1). Ответы получены 2026-10-30, анкету художник заполнил сам.

1. Опыт в 3D, риггинг и анимация: художник не моделирует руками и управляет агентами. Всё делает агент. Уровень — новичок, риггинга и анимации нет.
2. ОС и что установлено (Blender, Studio, Studio MCP, Blender MCP): Windows 11. Blender 5.2.3 LTS (Steam, `C:\Program Files (x86)\Steam2\steamapps\common\Blender\blender.exe`). Python 3.14.3 (есть и 3.11). Roblox Studio и Studio MCP — по словам художника есть, но 2026-10-30 в сессии агента Studio MCP не подключён (см. отчёт style test). Blender MCP нет и не нужен: агент управляет Blender скриптами (`blender --background --python <скрипт>`, `bpy`).
3. Подписки на AI-генераторы: нет, платить не готов. Можно бесплатное: `generate_mesh` / `generate_procedural_model` в Studio MCP и Creator Store (по §3: без скриптов, привести к палитре и бюджету).
4. Часов в неделю: время не ограничено, агент работает автономно. Художника спрашивать только о том, что без него не решить: загрузки, импорт в Studio, утверждение.
5. Что делает сам / что AI / что Creator Store: сам художник ничего не делает. Основной путь — процедурные модели скриптами Blender; черновики — бесплатные генераторы Studio MCP; базовые вещи — Creator Store.
6. Референсы стиля: нет, держимся стиля из `ASSETS_PROMPT.md` §2.

**Владение ассетами:** группы проекта в Roblox пока нет. Загрузки — с личного аккаунта в тестовом плейсе, как в TEST_01; каждый такой ID отмечается в отчёте и трекере и до продакшена перезаливается от группы.
