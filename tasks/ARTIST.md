# Задачи: Художник

Твой агент работает по `ASSETS_PROMPT.md`. Процесс и роли — `TEAM.md`.
Ты всегда на **одну фазу впереди** Разработчика. Если модель не успела, он ставит заглушку — ничего страшного, но не затягивай.

## Старт (один раз)

- [ ] Blender, Roblox Studio, Claude Code, Git, GitHub CLI (`gh auth login`); принять приглашение в репозиторий
- [ ] В Claude Code: `/plugin` → установить **Roblox Studio**; в Studio включить *Enable Studio as MCP server*
- [ ] По желанию: Blender MCP (агент сможет управлять Blender сам)
- [ ] Получить роль «Художник» в группе Roblox. **Всё загружать от имени группы**, не с личного аккаунта
- [ ] Создать отдельный тестовый плейс для проверки моделей
- [ ] Сказать агенту: «Прочитай TEAM.md и ASSETS_PROMPT.md, следуй им». Он начнёт с интервью и заполнит `assets/ARTIST_PROFILE.md`
