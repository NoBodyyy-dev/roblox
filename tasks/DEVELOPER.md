# Задачи: Разработчик

Твой агент работает по `AGENT_PROMPT.md`. Подробные критерии фаз — там же, §8. Процесс и роли — `TEAM.md`.
Ты сливаешь все Pull Request в `main` и публикуешь игру.

## Старт (один раз)

- [ ] Windows: Roblox Studio, Claude Code, Git, GitHub CLI (`gh auth login`)
- [ ] В Claude Code: `/plugin` → установить **Roblox Studio**; в Studio: Assistant → … → Settings → MCP Servers → *Enable Studio as MCP server*
- [ ] Создать репозиторий на GitHub, залить все файлы этой папки, пригласить Геймдизайнера и Художника
- [ ] Заменить заглушки логинов в `.github/CODEOWNERS` на реальные GitHub-логины
- [ ] Включить в настройках `main`: слияние только через Pull Request, обязательное одобрение Code Owners
- [ ] Завести доску GitHub Projects: *Бэклог → В работе → На проверке → Готово*, метки `дизайн`, `арт`, `разработка`, `баг`, `запрос`
- [ ] Получить роль «Разработчик» в группе Roblox; создать игру в группе (не на личном аккаунте) и плейсы Lobby, Desert, Sea, Mountains
- [ ] Сказать агенту: «Прочитай TEAM.md и AGENT_PROMPT.md, следуй им»
