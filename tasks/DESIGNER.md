# Задачи: Геймдизайнер

Твой агент работает по `DESIGN_PROMPT.md`. Процесс и роли — `TEAM.md`.
Ты всегда на **одну фазу впереди** Разработчика: готовишь правила и числа к фазе, которую он начнёт следующей.

## Старт (один раз)

- [ ] Claude Code, Git, GitHub CLI (`gh auth login`); принять приглашение в репозиторий
- [ ] Получить роль «Геймдизайнер» в группе Roblox (пассы, продукты, бейджи, аналитика)
- [ ] Если ты владелец проекта: создать группу Roblox, раздать роли (`TEAM.md` §4), **записать договорённость о долях дохода**
- [ ] Сказать агенту: «Прочитай TEAM.md и DESIGN_PROMPT.md, следуй им»

## По фазам

Номер — фаза, которую сейчас делает **Разработчик**. Ты в это время готовишь следующую.

- [ ] **Во время 0:** рабочее название; языки (EN + RU); правила лобби, дверей и группы
- [ ] **Во время 1:** спека карты пустыни: длина трассы, число и типы построек, доля дальних, ориентиры
- [ ] **Во время 2:** параметры седана и цели по ощущению езды; правила выживших (команды, посадка, зачёт)
- [ ] **Во время 3:** плейтест езды → правки; голод, жажда, солнце, инвентарь, лут-таблицы
- [ ] **Во время 4:** детали и диагностика: узлы, симптомы, износ, совместимость
- [ ] **Во время 5:** зомби, оружие, броня, заражение — все числа
- [ ] **Во время 6:** смерть и возрождение, пул побочных заданий с текстами, погода и сезоны, условие завершения пустыни
- [ ] **Во время 7:** **экономика:** курс Жетонов, цены в Robux и Жетонах, характеристики машин, наборы классов, формула очков, первые 20–30 ачивок; создать пассы, продукты и бейджи в Creator Dashboard, ID вписать в конфиг
- [ ] **Во время 8:** текст страницы игры; спека моря
- [ ] **Во время 9:** плейтест экономики → правки цен и курса
- [ ] **Во время 10:** новые постройки и события для пустыни; спека гор, вертолёта, бункера
- [ ] **Во время 11:** спека бесконечной игры: контракты, пороги улучшений бункера, уровни угрозы
- [ ] **Во время 12:** ачивки до 60–100, тексты контрактов
- [ ] **Во время 13 и после релиза:** баланс по аналитике — где бросают, что покупают, сколько рейсов до покупки

- [ ] Каждое изменение чисел — строка в `design/CHANGELOG.md`
- [ ] Разобрать Issues с меткой `дизайн`
