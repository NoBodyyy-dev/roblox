# 3D-модели «Спасение выживших»: бриф для Claude Design

31 октября 2026 · решение владельца (подготовлено помощником владельца, Mac-сессия) · живая версия: https://claude.ai/artifact/2Aoy1r4aTDJNAWmzAaatsB

## 1. Что это и общие правила для всех моделей

Этот бриф перечисляет все 3D-модели кооперативной Roblox-игры «Спасение выживших» (до 4 игроков: заброшенный город на машине → море на лодке → горы с вертолётом → бункер) и даёт задание на каждую модель и её текстуры. Источники: `Gameplay_Design.md` v0.8, `ASSETS_PROMPT.md` (каталог P0–P8, контракт §6), `design/specs/city.md` §12, `design/specs/lobby.md`, решения владельца от 31.10 (`design/decisions/2026-10-31-core-loop.md` §13). Уже готово и в этот бриф не входит: `Lobby_Hub`, `Lobby_Backdrop`, трое ворот лобби, `House_Small_01`, `Sedan` (style test), `Rock_Desert_01`, палитра `T_Palette_Main`.

**Как читать «реалистично и проработанно».** Стиль игры утверждён: low-poly с одной палитрой-текстурой, без фототекстур (`ASSETS_PROMPT.md` §2). Реализм здесь означает правдоподобные пропорции, узнаваемые силуэты, детали износа в геометрии (вмятины, проломы, сколы, провисшие провода) и честную грязь цветом из «потрёпанной» палитры. Если владелец хочет полноценные PBR-текстуры на главных объектах (машина, враги, оружие), это смена стиля: решение владельца, отдельным пунктом в §10.

**Правила, общие для каждого задания ниже:**

| Правило | Значение |
| --- | --- |
| Масштаб | По персонажу R15: рост ≈ 5 studs, дверной проём 7–8 × 4, этаж 10–12, седан 14–16 studs в длину |
| Ориентация и pivot | Перёд в −Z; низ на земле (Y = 0); pivot зданий и пропов в центре основания, у дверей, колёс, капотов и роторов — на оси вращения |
| Сетка | Модули построек и дорог кратны 4 studs, стыкуются без щелей |
| Бюджет треугольников | Мелкий проп 50–300; средний (ящик, оружие, колесо) 300–1 500; крупный проп 500–3 000; модуль постройки 50–500; здание ≤ 8 000; машина ≤ 8 000; лодка и вертолёт ≤ 10 000; персонаж и зомби ≤ 4 000; один меш никогда не выше 20 000 |
| Текстура по умолчанию | Палитра-атлас `T_Palette_Main` 512², UV каждого полигона в центр ячейки, не ближе 6 px к краю; имена ячеек из `assets/palette/palette.json` |
| Износ | Второй вариант цвета — палитра `T_Palette_Worn` (те же ячейки, грязнее); форма износа — геометрией |
| Исключения из палитры | Скины машин 1024² (`SurfaceAppearance`, Overlay, альфа = краска), стекло с трещинами 512² альфа, знаки и вывески-пиктограммы 256–512², террейн-материалы Color + Normal 512² |
| Формат сдачи | FBX из Blender → импорт в Studio от имени группы «Грева нет» (ID 867558223) → одна `Model` в `.rbxm` в `assets/rbxm/<Category>/<Name>.rbxm`: `PrimaryPart` задан, `Anchored`, декор без коллизии, без скриптов, атрибуты `AssetId`, `Category`, `Tris` |
| Коллизия | `CollisionFidelity` Box или Hull; сложная форма — отдельной невидимой частью `Collider_N` |
| Текст | На моделях и текстурах текста нет: пиктограммы; игра на двух языках |
| Кровь | Без натуралистичной крови: тёмные или пыльные следы (возрастной рейтинг Roblox) |
| Имена | Английские, `PascalCase`: `Sedan_Body`, `House_Wall_Window`, `Item_SparkPlug` |
| Иконка предмета | Для каждого предмета и оружия: рендер 512² с прозрачным фоном, одна камера и свет для всех, в `assets/icons/<Name>.png` |
