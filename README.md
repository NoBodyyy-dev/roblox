# Заброшенный город — v0.1.0

Первая версия окружения кооперативной Roblox-игры. Утверждённый вариант: город вместо пустыни, естественный овраг к морю и разрушенный мост в конце.

- Карта шириной 6400 studs.
- 25 зданий с доступом: 5 недалеко от трассы, 20 по ширине и длине карты. Положение, повороты, размеры и этажность различаются; seed фиксирован для восстановления.
- 2–5 этажей с лестницами. 95 закрытых домов без лута, 85 фоновых высоток.
- Городская панорама, руины, обломки, улицы.
- Мост в конце маршрута; естественный спуск по Terrain к морю, без лестниц и гигантских пересекающихся плит.

## Восстановление карты

1. Откройте **новый Baseplate** в Roblox Studio.
2. В режиме редактирования вставьте весь файл [tools/BuildCityV1.luau](tools/BuildCityV1.luau) в Command Bar и выполните. Во время построения рельефа дождитесь завершения.
3. Сохраните карту через File → Save to File как AbandonedCity-v0.1.0.rbxl.

Сборщик создаёт ModuleScripts в ServerStorage.CityV1Sources. Отдельные исходники находятся в tools/. Ранние варианты побережья временно строятся для восстановления одинаковых руин, затем переносятся в ServerStorage; активная карта использует только финальный Terrain. При публикации игры резервные модели можно удалить после сохранения отдельной копии.

Файл открытого плейса .rbxl не экспортирован автоматически. Версия содержит исходники, которые воспроизводят карту, и оригинал фонового изображения. Панорама использует Roblox asset rbxassetid://83137947733144; при ограничениях доступа загрузите assets/CityPanorama.png в свою группу и замените ID в BaseCity.luau и BuildCityV1.luau.

## Проверка и ограничения

В Studio проверены пути на верхние этажи всех 25 зданий и естественный спуск к морю. Последний овраг просмотрен сверху и с уровня земли. Проверка построения этой отдельной упаковки сборщика ещё не выполнялась; работающая карта проверялась поэтапно в Studio.

Это версия окружения: транспорт, лодка, NPC, лут, бой, задания и сохранение игрового прогресса пока не реализованы. Мобильная производительность и совместная игра ещё не проверены.

Фоновая панорама создана ImageGen. Это исходный графический материал проекта.
