# Проверки v0.1.2

Файл релиза: [AbandonedCity-v0.1.2.rbxl](../../../places/AbandonedCity-v0.1.2.rbxl).

Мобильные и многоклиентные тесты геометрию не меняли; временные объекты удалены.
